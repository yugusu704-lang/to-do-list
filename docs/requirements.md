## 决策确认记录

| 决策点 | 决策结果 | 备注 |
|--------|---------|------|
| 数据存储 | localStorage | 离线本地存储，无需后端/云端 |
| 任务分类 | 自定义分类 | 用户手动创建分类（如"工作""生活""学习"），**P0 完成后再迭代加入** |
| 提醒通知 | 不做 | P2 范围，不实现 |
| 删除方式 | tap-to-reveal | 点击任务行，右侧滑出红色删除按钮；桌面端 hover 也能触发 |
| 完成效果 | 划线 + 变灰 + 绿色圆圈 | 圆圈变绿 #16A34A 填充，文字变灰 #A8A29E + 划线，0.2s 过渡动画 |
| 筛选方式 | Tab 切换 | 底部或顶部三个标签页（全部/进行中/已完成），点击切换高亮 |
| 首次体验 | 直接进列表 | 无引导页，空状态时显示友好提示文字 |

---

## P0：必须实现（MVP）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 添加任务 | 底部输入框 + 回车/按钮提交，空输入不提交 |
| 2 | 完成/取消完成 | 点击任务左侧圆圈切换，划线 + 变灰动画 |
| 3 | 删除任务 | tap-to-reveal：点击/悬停任务行，右侧显示红色删除按钮 |
| 4 | 数据持久化 | localStorage，关闭再打开不丢失，需 try-catch 保护 |
| 5 | 筛选视图 | Tab 切换：全部 / 进行中 / 已完成 |

---

## P1：锦上添花（P0 完成后迭代）

| # | 功能 | 说明 |
|---|------|------|
| 1 | 编辑任务 | 点击任务文字进入编辑模式，按回车或失焦保存 |
| 2 | 任务计数 | 标题下方显示剩余未完成数量 |
| 3 | 清除已完成 | 一键清除所有已完成任务 |
| 4 | 自定义分类 | 用户创建分类，任务归属某个分类，筛选栏增加分类 Tab |

---

## P2：不做

- 用户登录/注册
- 后端 API / 云同步
- 截止日期 / 提醒通知
- 拖拽排序（复杂度高，优先级低）

---

## 技术约束

| 约束 | 说明 |
|------|------|
| 框架 | React 18+ 函数组件 + Hooks |
| 样式 | Tailwind CSS v4，className 直接写在 JSX |
| 测试 | Vitest + @testing-library/react，TDD（RED→GREEN→REFACTOR） |
| 状态管理 | useState / useReducer，不用 Redux |
| 动效 | 纯 CSS transition，不引入动画库 |
| 依赖 | 不引入额外依赖，除非确实必要 |

---

## UI 规范摘要

- 背景色：#FAFAF9（暖白）
- 主色调：#2563EB（蓝色，用于按钮/高亮）
- 完成色：#D4D4D4（浅灰）
- 危险色：#DC2626（红色，仅删除按钮）
- 字体：系统默认
- 最大宽度：480px 居中
- 圆角不超过 12px
- 不使用渐变、重阴影

---

## 数据模型（为 P1 分类功能预留）

```javascript
// 任务对象结构
{
  id: string,           // 唯一 ID（Date.now() 或 crypto.randomUUID()）
  text: string,         // 任务内容
  completed: boolean,   // 是否完成
  category: string,     // 分类（P1 阶段实现，默认为 null）
  createdAt: number     // 创建时间戳
}
```
