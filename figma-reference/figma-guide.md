## 画板设置

- **名称：** 待办清单 - iPhone 14 Pro

## 5. 任务项（核心组件）

每个任务项是一个自动布局 Frame。

### 基础尺寸

| 属性 | 值 |
|------|-----|
| 宽度 | 375px（全宽） |
| 高度 | 自动 |
| 内边距 | 14px 16px |
| 背景 | `#FFFFFF` |
| 下边框 | 1px `#F0F0F0` |

### 元素列表（从左到右）

**a) 圆圈复选框**

| 属性 | 值 |
|------|-----|
| 尺寸 | 22 × 22px |
| 圆角 | 50%（完全圆形） |
| 边框 | 2px `#2563EB` |
| 背景（未完成） | 透明 |
| 背景（已完成） | `#16A34A` |
| 内容 | 白色对勾 SVG，12 × 12px |

**对勾 SVG：**
```svg
<svg width="12" height="12" viewBox="0 0 12 12" fill="none">
  <polyline points="2,6 5,9 10,3" stroke="white" stroke-width="2"
    stroke-linecap="round" stroke-linejoin="round"/>
</svg>
```

**b) 任务文字**

| 属性 | 值 |
|------|-----|
| 字号 | 16px |
| 行高 | 1.5（24px） |
| 颜色（未完成） | `#1C1917` |
| 颜色（已完成） | `#D4D4D4` |
| 删除线（已完成） | 有 |
| 字重 | 400 (Regular) |

**c) 删除按钮**

| 属性 | 值 |

## 快速操作

1. **打开 Figma** → 新建文件
2. 按上面的规格画出 5 个区域（状态栏 → 标题 → 筛选 → 列表 → 底部栏）
3. 截图发给我，我对比参考稿给你优化意见
4. 定稿后告诉我精确数值，我直接改代码
