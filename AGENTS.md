# DevFlow Project Governance Rules for to-do-list

This workspace follows the DevFlow rigorous development workflow:
1. **Evidence over Opinions**: Cite exact filenames and line numbers for all architectural claims.
2. **Pre-Implementation Alignment**: Use `grill-me` to clarify requirements or run `devflow review "<proposal>"` for dual-blind consensus.
3. **Execution**: Follow TDD (Test Driven Development) and modular parallel isolation (Octopus pattern).
4. **Verification**: Multi-perspective code review (Bee pattern) before marking any task complete.
5. **Memory**: All key architectural decisions must be findable and recorded in DevFlow memory.
