# 📝 待办清单 (Minimalist To-Do List)

> 一款基于 **React + Tailwind CSS + Capacitor + Android 原生 SQLite & 桌面小组件** 构建的极简高质感待办事项应用。

---

## ✨ 核心特性

### 📱 强大的 Android 桌面小组件 (Widgets)
- **多尺寸支持**：提供 **4×2** 与 **4×3** 两种标准桌面小组件规格。
- **列表滚动浏览**：小组件内嵌 ListView，无需进入 App 即可直接在手机桌面上滑动翻阅今日所有任务。
- **一键完成与动效**：点击小组件复选框直接标记完成，并伴随平滑淡出的完成动效。
- **快捷唤起添加**：点击小组件右上角 `+` 按钮，一键直达 App 并自动聚焦输入法。
- **每日零点自动刷新**：每日午夜 0:00 自动无感刷新今日待办与任务顺延。

### 🌓 全局深色模式与小组件自适应同步
- **温暖深炭黑设计**：遵循极简设计规范（背景 `#121214`、卡片 `#1C1C1F`、文字 `#F4F4F5`），夜间柔和护眼。
- **手动三态开关**：顶部右上角支持 **跟随系统 (🌗) ⇄ 浅色模式 (☀️) ⇄ 深色模式 (🌙)** 循环切换，偏好自动持久化。
- **桌面小组件毫秒级联动**：在 App 内切换显示模式时，桌面小组件全要素（底色、文字、图标、复选框）1:1 即时深度同步。

### 💾 高容量原生 SQLite 存储引擎
- **万级数据支撑**：底层采用 Android 原生 SQLite 数据库，支持海量待办的高频写入与秒级检索。
- **自动无损迁移**：内置存量数据自动迁移引擎，首次启动 100% 自动无感迁移旧版历史任务。

### 🔄 智能跨天顺延与时间流分组
- **过期自动顺延**：未完成任务在跨天时自动顺延至“今天”，重要事项绝不遗漏。
- **智能日期分组**：按 `无日期`、`今天`、`明天`、`后天`、`具体日期`、`已过期` 自动聚合，组内严格按时间升序排列。

### ✏️ 任务就地编辑与长文本自适应
- **就地快速编辑**：点击任务专属铅笔图标即可就地修改内容、截止时间与地点，支持回车保存与 Esc 取消。
- **防误触体验**：取消点击文字直接激活编辑，杜绝列表滑动或浏览时的误触。
- **长文本自然折行**：App 内长文本 100% 自动折行完整阅读；桌面小组件支持最多 3 行折行排版。

### 📐 全尺寸安卓多屏幕与折叠屏自适应
- **黄金阅读容器**：常规手机 100% 满宽自然舒展；折叠屏大屏、平板或横屏模式下自动启用 `max-w-xl` 居中容器，视线聚焦舒适。
- **全面屏手势与键盘协同**：严密适配 `safe-area-inset-*`，软键盘唤起时页面高度顺滑避让（`adjustResize`）。

## 🚀 快速上手与本地开发

### 1. 环境准备
- [Node.js](https://nodejs.org/) (>= 18.0.0)
- [Android Studio](https://developer.android.com/studio) (带 Android SDK / Command-line Tools)
- Java JDK 17+

### 2. 安装依赖
```bash
git clone https://github.com/yugusu704-lang/to-do-list.git
cd to-do-list
npm install
```

### 3. 本地前端开发与测试
```bash
# 启动 Vite 开发服务器
npm run dev

# 运行全量单元测试
npm run test
```

### 4. 同步至 Android 原生工程
```bash
# 构建前端产物并同步到 Capacitor Android 资产目录
npm run build
npx cap sync android
```

### 5. 编译生成 Android APK
```bash
# Windows 快速构建 Debug APK
android\build-debug.bat

# 或使用 Gradle 命令行编译
cd android
./gradlew assembleDebug
```
> 编译生成的安装包将自动保存在 `apk-releases/` 目录下。
