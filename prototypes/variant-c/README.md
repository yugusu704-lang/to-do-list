# Variant C — 分组卡片（Warm Organized）

## 设计立场

**"温暖的组织感"** — 任务按时间自动分组（今天/明天/昨天），每组一个容器，既有结构又不冰冷。参考 Microsoft To Do 的分组风格。

## 关键选择

| 维度 | 决策 |
|------|------|
| 布局 | 分组卡片，按日期分组，每组有小标题 |
| 排版 | 组标题 11px uppercase + 字间距，任务右侧显示日期标签 |
| 配色 | 暖白背景，白色分组卡，绿色（#16A34A）用于完成态（区别于 A/B 的蓝色） |
| 交互 | 完成用绿色（暗示"完成 = 好事"），筛选用竖线分隔的文字标签 |
| 分组 | 按日期自动分组（今天/明天/昨天/更早），增强时间感知 |

## 优势

- 时间分组提供天然的上下文，帮用户做优先级判断
- 绿色完成态在心理上更积极（vs 蓝色中性）
- 日期标签增加信息密度，无需额外操作

## 劣势

- 实现复杂度最高（需要日期分组逻辑）
- 对于一次性任务清单，分组可能显得多余
- 日期标签在任务少时显得空荡

## 最适合

- 日常任务管理，任务有时间维度
- 喜欢 Microsoft To Do 风格的用户
- 需要快速判断"今天该做什么"的场景
