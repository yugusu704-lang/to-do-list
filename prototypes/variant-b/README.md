# Variant B — 卡片结构（Structured Clarity）

## 设计立场

**"有序的清晰"** — 每个任务都是独立的卡片，有轻微的阴影和层次感。参考 Todoist 的卡片式布局，但保持极简。

## 关键选择

| 维度 | 决策 |
|------|------|
| 布局 | 卡片式，每个任务独立圆角白卡，间距 8px |
| 排版 | 标题 24px bold，计数器用 pill 样式徽章 |
| 配色 | 灰色背景 #F5F5F4，白色卡片，筛选栏用实心 pill（黑色选中） |
| 交互 | hover 卡片上浮 + 阴影加深，圆圈始终蓝色边框，完成填充 |
| 筛选 | Pill 标签，选中态实心黑底白字，更醒目 |

## 优势

- 任务之间有清晰的视觉边界
- 卡片 hover 动效提供良好的交互反馈
- 适合任务较多的场景（卡片分隔不会混成一片）

## 劣势

- 卡片间距占用空间，一屏显示任务数较少
- 阴影和卡片在小屏上可能显得"重"
- 比变体 A 多一层视觉噪音

## 最适合

- 喜欢有结构感界面的用户
- 任务类型多样，需要视觉区分
- 从 Todoist 迁移的用户（熟悉卡片感）
