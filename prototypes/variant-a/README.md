# Variant A — 极简列表（Invisible UI）

## 设计立场

**"内容即界面"** — 去掉一切容器和装饰，让任务本身成为唯一的视觉元素。参考 Apple Reminders 的极简列表风格。

## 关键选择

| 维度 | 决策 |
|------|------|
| 布局 | 纯列表，无卡片、无分组，全宽排列 |
| 排版 | 标题 28px bold，正文 15px normal，层级靠字号和字重区分 |
| 配色 | 暖白背景 #FAFAF9，蓝色主色仅用于圆圈完成态和筛选底线 |
| 交互 | hover 显示删除按钮，圆圈点击切换完成，删除向左滑出 |
| 圆圈 | 灰色细边框（未完成）→ 蓝色填充 + 白色勾（完成） |

## 优势

- 极高信息密度，一屏可显示更多任务
- 视觉干扰最少，专注任务本身
- 实现简单，组件少

## 劣势

- 缺乏视觉层次，大量任务时显得单调
- 没有分组概念，任务混在一起
- 在浅色背景下，任务项之间的分隔可能不够明显

## 最适合

- 任务量适中（5-20 条）的个人用户
- 追求纯粹效率、不喜欢视觉装饰的用户
- iOS 用户（与系统风格一致）
