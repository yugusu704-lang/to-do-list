# Variant D — 融合方案（分组 + 卡片）

## 设计立场

**"有温度的结构"** — 融合 C 的时间分组提供上下文，B 的卡片层次提供视觉质感，绿色完成态传递积极反馈。

## 来源融合

| 元素 | 来源 | 说明 |
|------|------|------|
| 时间分组 | Variant C | 今天/明天/昨天自动分组，组标题 12px uppercase |
| 卡片样式 | Variant B | 白色圆角 12px 卡片，`box-shadow` + hover 上浮 |
| 完成色 | Variant C | 绿色 #16A34A（区别于主按钮蓝 #2563EB） |
| 筛选样式 | Variant A | 底线高亮，简洁不占空间 |
| 删除交互 | Variant A | hover 显示红色 ×，轻量 |

## 最终配色

```
背景色：    #FAFAF9（暖白）
卡片色：    #FFFFFF + box-shadow
主文字：    #1C1917
次要文字：  #78716C
主色调：    #2563EB（筛选底线、输入框聚焦、添加按钮）
完成色：    #16A34A（绿色，圆圈填充）
危险色：    #DC2626（删除按钮）
```
